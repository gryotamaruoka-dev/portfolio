毎日の定型作業をAIで自動化し、1回30分を5分に

担当者の作業に1日つきそって流れを書き出し、AIに任せられる作業を選んで仕組みにしました。このページでは、そのうち「解析依頼書の作成」と「クレームの集計」の2つを紹介します。2週間以内に使い始めてもらい、ほかの担当者や部署にも広げています。

前の課題

  • 毎日くり返す定型作業（解析依頼書の作成）に、1回30分かかっていた
  • Excel での集計に、1回1時間かかっていた
  • どちらも、メールや既存のシステムから人が目で拾い、Excel に書き写す作業だった

進め方

  1. 担当者に8時間つきそい、作業を1つずつ書き出す（何を見て、何を判断し、何を作るか）
  2. AIに任せる作業と、人が見る作業を分ける
  3. AIの仕組みを作り、お客様の環境に入れる（2週間以内に使い始め）
  4. ほかの担当者・部署に広げる

作業 1解析依頼書の作成（1回30分 → 5分）

Outlook で依頼が届くと、棚にある現物の情報・現物に付いた検査結果の紙・検査担当者の情報から、テンプレートの Excel で解析依頼書を作り、印刷して解析の担当に渡す業務です。

前の課題

  • 依頼は Outlook のメールで届き、1通ずつ開いて内容を拾っていた
  • 棚の現物に書かれた情報と、現物に付いた検査結果の紙を、目で見てテンプレートの Excel に書き写していた
  • 検査担当者の情報も、毎回調べて入力していた

業務の流れがどう変わるか

いま

  1. Outlook の依頼メールを1通ずつ開く
  2. 現物と検査結果の紙を見て書き写す
  3. 検査担当者の情報を調べて入れる
  4. テンプレートの Excel で依頼書を仕上げる
  5. 印刷して解析の担当に渡す
人の作業 5つ・1回30分

これから

  1. AIに頼み、依頼メールをまとめて取り込む
  2. 現物と検査結果の紙を撮影して添付する
  3. 写真の文字を読み取り、担当者の情報を取得して、依頼書を作る
  4. 確認して印刷し、解析の担当に渡す
人の作業 3つ・1回5分

色の付いた段は、仕組み（AI・自動処理）が行います。ほかは人の作業です。

仕組みにした所

  1. AI（Codex。作業を頼めるAI）に頼むと、Outlook の依頼メールをまとめて取りに行く
  2. 現物の情報と検査結果の紙は、写真を撮って添付するだけ。写真の文字は AI が読み取る
  3. 検査担当者の情報は、クラウドから自動で取得する
  4. 必要な情報がそろうと、テンプレートの Excel で解析依頼書を作る

作業 2クレームの集計（Excel での集計 1回1時間 → 10分）

既存のシステムからクレームのデータを書き出し、Excel に写して形をそろえ、Power BI（グラフを作る道具）でグラフにする定期の集計です。

前の課題

  • クレームのデータは、既存のシステムの画面から毎回手で書き出していた
  • 書き出したデータを Excel に写し、形をそろえる補正も手作業だった
  • 集計のたびに、決まった担当者の時間を取っていた

業務の流れがどう変わるか

いま

  1. 既存システムの画面を開き、データを書き出す
  2. 書き出したデータを Excel に転記する
  3. 形をそろえて補正する
  4. Power BI に読み込ませてグラフにする
人の作業 4つ・1回1時間

これから

  1. AIに集計を頼む
  2. AIがブラウザを操作して、システムから書き出す
  3. 補正して Excel に出力する
  4. Power BI に読み込ませる
人の作業 2つ・1回10分

色の付いた段は、仕組み（AI・自動処理）が行います。ほかは人の作業です。

仕組みにした所

  1. AI（Codex）が人の代わりにブラウザの画面を操作し、既存のシステムからデータを書き出す
  2. 書き出したデータの補正は、AI が補正用のスクリプト（Python・Node.js）を動かして行う
  3. 補正したデータの Excel への出力まで AI が行い、人は頼むだけにした
  4. Power BI への読み込みは人が行い、グラフの作りは変えていない

担当した内容をもとにした、業務のイメージです。実際の画面ではありません。

工夫した所

今の道具と出力の形は変えない

Power BI のグラフも、依頼書のテンプレートも今のままです。変えたのは、そこへ持っていくまでの手作業だけです。

既存のシステムは入れ替えない

システムに手を入れず、AI が人と同じように画面を操作してデータを書き出す形にしました。

人が見る所を残す

写真の撮影、最後の確認、印刷と手渡しは担当者が行います。全部をAIに任せる形にはしていません。

よくある質問

全部の作業をAIに任せるのですか？

いいえ。担当者の作業を書き出したうえで、AIに任せる作業と人が見る作業を分けます。この事例でも、確認・印刷・手渡しは担当者が行っています。

使い始めるまで、どのくらいかかりますか？

この事例では、作る作業を決めてから2週間以内に使い始めてもらいました。

今のシステムを入れ替える必要はありますか？

この事例では入れ替えていません。既存のシステムはそのままで、AI が画面を操作してデータを書き出しています。
